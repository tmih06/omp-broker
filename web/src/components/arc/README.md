# Arc components

Generated into this directory from the [Arc registry](https://uiarc.dev) with the shadcn CLI.
Source: [kuratlielia/arc-library](https://github.com/kuratlielia/arc-library), MIT licensed — see `LICENSE`.

Add more items from `web/`:

```bash
bunx shadcn@latest add @uiarc/dialog
```

The registry is declared in `web/components.json`. Re-running an add overwrites the item, so keep local edits in mind.
