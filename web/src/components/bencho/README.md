# StackedBars

The usage widget comes from [Bencho](https://bencho.dev) and is MIT licensed
([licence](https://bencho.dev/licence)). The source and its comments live in
`StackedBars.tsx`; the styles are appended to `web/src/index.css`.

Bencho's tokens are mapped locally on the component root:

| Bencho token  | Project token  |
| ------------- | -------------- |
| `--fill-on`   | `--foreground` |
| `--fill-slab` | `--surface`    |
| `--font-ui`   | `--font-body`  |
| `--pane-edge` | `--border`     |

`--c`, `--i`, `--stb-r`, and `--stb-rr` are set by the component itself.
